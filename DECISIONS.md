# {{PROJECT_NAME}} — Decision Log

Canonical registry of **emergent decisions** — the forks that appear when code meets reality, within
already-approved scope (market equivalent: Decision Log / Decision Register; the recommend↔ratify
axis follows RAPID semantics: agents recommend, {{DECIDER}} decides). Governed by
`.claude/skills/decision-log/SKILL.md`.

- `PD-` reads **"Project Decision"**. This file holds **live** decisions (`OPEN`, `NEEDS_VALIDATION`,
  `DEFERRED`) plus the full index; closed ones live in `DECISIONS_ARCHIVE.md`.
- New features/tech → `docs/rfc/`. Locked decisions → `docs/adr/`.
- Never edit the index by hand: `python3 scripts/planning/decision-index.py` after any PD change
  (`--check` runs in CI and enforces the sensitive-default hard gate).

## Entry template (v3)

```markdown
## PD-{scope}-{NN} — {short title}

- **Status:** `OPEN` | `NEEDS_VALIDATION` | `DEFAULT_APPLIED` | `DEFERRED` | `RESOLVED (who, YYYY-MM-DD)`
- **Impact:** `architectural` | `operational` | `business`
- **Proposed-by:** {role}
- **Reversibility:** `two-way` | `one-way`
- **Sensitivity:** `internal` | {a value from SENSITIVE_DOMAINS}
- **Scope:** `local` | `org`
- **Ratified-by:** — | {{DECIDER}} (YYYY-MM-DD, digest | direct | auto, lapse) | owner:{area} (YYYY-MM-DD)
- **Story(s):** T-NNN
- **ADR(s):** ADR-NNN
- **Context:** {1–2 sentences}
- **Alternatives:**
  - A: {option} — {trade-off}
  - B: {option} — {trade-off}
- **Proposed default:** {which and why}
- **Reopen-trigger:** {verifiable condition — prefer data over story status} _(when DEFERRED)_
- **Resolved:** {date} — {decision + justification}
```
